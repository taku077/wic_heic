HEICのGPU復号・読み取り専用テスト（研究用）
=================================================

目的：使用中のWindows 10内蔵Intel GPUで、HEVC Main10をD3D11VAで実際に復号できるか確認する。
正常終了した場合もExplorerやWindows標準「フォト」が高速化されるわけではない。

確認内容：
- 同梱する3件の固定HEVC人工サンプル（04.h265、fixture-irot3-exif6-noaux.h265、synthetic12mp_detail.h265）のみを読み取る。3件目は4032×3024・10bitの高負荷人工画像。
- ソフトウェア復号結果を確認した後、GPUアダプター番号0～3を調査。
- FFmpegのAV_PIX_FMT_D3D11テクスチャが実際に得られ、CPU転送に成功した場合だけ「GPU実復号」を認定。
- 色・画素の一致度、復号時間、GPU初期化とCPUへの読み戻し時間をログに残す。
- 実機のHEIC原本、フォルダ内の個人画像、ユーザーファイルには一切アクセスしない。
- コーデック登録、MSI、インストール、管理者権限、ネットワーク通信、常駐処理は行わない。
- Run_GPU_ReadOnly.cmdだけがログをZIP展開先に新規作成し、再実行時も別名で保存する。
- プログラム本体は標準出力へ検査結果を表示するのみで画像を保存しない。

注意：
- GitHub Actionsがコンパイルした署名なしのWindows実行ファイル（管理者権限不要）。
- ダウンロードしたファイルは自分で信頼性を確認してください。セキュリティ警告の無効化を要求しません。
- これは研究用ツールであり、既存WIC/Photos/HEIC Managerを変更しません。
- 同梱のFFmpeg LGPL共有DLLは、固定されたBtbN配布物のSHA-256をCIで検証してからコピー。

使い方：
1) ZIPを任意のフォルダへ展開（実行ファイルだけ移動しないこと）。
2) Run_GPU_ReadOnly.cmd を実行。PowerShellの実行ポリシー変更不要。
3) 生成されたGPU_Readonly_Result_数字_数字.txtのみチャットへアップロード。
4) テスト後は展開したフォルダごと削除可能。Windowsの設定には何も残さない。

GPUの12MP復号に成功しても製品採用とは扱わない。実際の写真の向き、HDR、ICC、10～30件の実測が別途必要。

追加した判定と安全性（2026-10-22）
- D3D11HevcCaps.exe は各GPUのHEVC Main/Main10、P010/NV12、12MPと対象フレーム寸法での対応状況を表示するだけです。
- WARP、Microsoft Basic Render、Intel以外のGPUについては「Intel GPU実復号成功」と認定しません。
- ハードウェアのBGRAがCPUと不一致（最大RGB差4超、平均RGBA差0.25超）の場合、復号が行われても成功判定しません。これは試験用の暫定しきい値であり、最終的な画像品質の認定ではありません。
- ランチャーは GPU_Readonly_Result_乱数_乱数.txt へ保存し、既存のログを上書きしません。
- Windows CIは、FFmpegや開発ツールがPATH上にない状態でも同梱DLLだけで固定HEVC3件のCPU復号が動くか確認します。
- 診断用の画像データはこの固定HEVC3件だけであり、利用者のHEIC/JPEG、カメラ画像、個人データを走査しません。

12MP（4032×3024）での注意点：
- GPUのHEVC Main10対応が表示されても12MPの復号を実際に実行できるとは限りません。そのため3件目の人工フレームを追加しています。
- 1080p/2048pxでGPU成功、12MPだけ失敗した場合は、12MPは従来の安全なソフトウェア復号へ戻す候補です。
- 12MP復号時間はこのPC上の参考値として記録します。実際のExplorer初回表示時間ではありません。

実機診断で判明した適用範囲（2026-10-22）
- 2048×2048と1920×1080の固定HEVCは10bitながらHEVC Rext（Range Extensions）。第7世代 Intel HD Graphics 620のMain10対応だけではハードウェア復号可能と判断できない。実機でハードウェア初期化失敗を観測したため、研究用経路はソフトウェアへ安全に戻す。
- 高負荷4032×3024サンプルはHEVC Main 10プロファイル。Intel GPUによる復号と全BGRA画素の一致を実機で確認。
- 再試験版は3回のCPU/GPU画像処理時間を計測し、デコーダー処理、GPU→CPU転送、色変換を分けて中央値を報告する。ユーザーの本物のHEICを読み込むものではない。
- 改善率は画像処理工程のみであり、Explorer初回サムネイルの改善率ではない。
