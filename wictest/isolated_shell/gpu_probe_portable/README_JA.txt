HEICのGPU復号・読み取り専用テスト（研究用）
=================================================

目的：使用中のWindows 10内蔵Intel GPUで、HEVC Main10をD3D11VAで実際に復号できるか確認する。
正常終了した場合もExplorerやWindows標準「フォト」が高速化されるわけではない。

確認内容：
- 同梱する2件の固定HEVC人工サンプル（04.h265、fixture-irot3-exif6-noaux.h265）のみを読み取る。
- ソフトウェア復号結果を確認した後、GPUアダプター番号0～3を調査。
- FFmpegのAV_PIX_FMT_D3D11テクスチャが実際に得られ、CPU転送に成功した場合だけ「GPU実復号」を認定。
- 色・画素の一致度、復号時間、GPU初期化とCPUへの読み戻し時間をログに残す。
- 実機のHEIC原本、フォルダ内の個人画像、ユーザーファイルには一切アクセスしない。
- コーデック登録、MSI、インストール、管理者権限、ネットワーク通信、常駐処理は行わない。
- Run_GPU_ReadOnly.cmdが唯一「GPU_Readonly_Result.txt」をZIP展開先に新規作成する（再実行時はログを書き直す）。
- プログラム本体は標準出力へ検査結果を表示するのみで画像を保存しない。

注意：
- GitHub Actionsがコンパイルした署名なしのWindows実行ファイル（管理者権限不要）。
- ダウンロードしたファイルは自分で信頼性を確認してください。セキュリティ警告の無効化を要求しません。
- これは研究用ツールであり、既存WIC/Photos/HEIC Managerを変更しません。
- 同梱のFFmpeg LGPL共有DLLは、固定されたBtbN配布物のSHA-256をCIで検証してからコピー。

使い方：
1) ZIPを任意のフォルダへ展開（実行ファイルだけ移動しないこと）。
2) Run_GPU_ReadOnly.cmd を実行。PowerShellの実行ポリシー変更不要。
3) 生成されたGPU_Readonly_Result.txtのみチャットへアップロード。
4) テスト後は展開したフォルダごと削除可能。Windowsの設定には何も残さない。

GPU_SUCCESS が表示されても製品採用とは扱わない。実際の写真の向き、HDR、ICC、10～30件の実測が別途必要。
