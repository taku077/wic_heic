# WicHeic 1.1.33 ― Windows10 CPU負荷軽減・フォトgrid修正版（RC）

## 目的

**PC全体がCPU使用率100%に達して重くなる問題の緩和**。前版1.1.32ではCOM Surrogateのgrid処理が軽くなった一方、Windowsフォトが高いCPUを占有する場面があった。表示速度短縮を目的とする変更ではない。

## 1.1.32との相違

- Explorer/dllhostの8bit不透明12MP gridでは既存のタイル2/HEVC1制限を維持。
- **Windowsフォト**の4論理CPU環境で、**6MP以上・8bit・アルファなし・HEIFの正規grid（複数タイル）**に限り、**タイル4→2、HEVCコーデック2→1**に制限。
- 通常HEIC、Exif/ICC、10/12bit、アルファ、非gridなどへの新しい制限は加えない。フォトの回転・保存機能、他社ハンドラー、ユーザーの原本は変更しない。
- 研究用のGitHub Actions環境変数は実機では利用しない。Windows10自体に一律のOS設定変更を行わない。
- **Shell専用COMハンドラーは本MSIに含めない**。別の研究ではCPU消費を減らせることを確認したが、grid・HDR・ICCの実画像に適用できないため現時点では非搭載。

## 実機評価時の注意

1. **旧1.1.32 MSIを保管**。不具合時は1.1.33をアンインストール後に旧版へ戻す。
2. HEIC原本は**開いて表示するのみ**。回転保存の実機テストは人工HEICコピーだけ。復元済みIMG_4074原本は使用しない。
3. 同じ程度のHEIC画像群を閲覧し、**タスクマネージャーのPC全体のCPUが100%になる時間、フォトプロセスのCPU、COM Surrogate、フォトの応答、サムネイルの待ち時間**を観察する。体感評価と数値の両方が必要。
4. 回転保存不可・向きの違い・画素や色の異常が増えたら不採用。
5. WPR/ETLの大容量録画を再度要求しない。必要最小限のCPU観測から進める。
6. 1.1.32と1.1.33の比較は画像枚数・表示操作・キャッシュ状態・フォトの同時起動状況をできる限り揃える。CPUピークが一度100%になっただけで効果ゼロと判断せず**持続時間**を比較する。

## 配布規則

全CI合格後、**1MB前後の軽量ZIP（MSI・日本語説明書・SHA256）とMSI単体**を同時に提供。大容量のHEIC人工試験素材を同梱しない。MSIのSHA256をGitHub Actionsの生成物と照合する。GitHubからの代替ダウンロード先を示す。**CI合格≠Windows10実機検証済み**。
