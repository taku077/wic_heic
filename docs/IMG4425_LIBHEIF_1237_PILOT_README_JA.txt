IMG_4425 / WIC for HEIC 1.1.29, libheif 1.23.7 - Windows 10 experiment
============================================================================
Status: Windows x64 GitHub Actions verified; Windows 10 Photos UI unverified.
This pilot is not proof that the historic IMG_4425 failure is resolved.

Changes:
- libheif upgraded from v1.23.1 to v1.23.7 including grid parallel decoder fixes.
- Authenticated lossless rotations preserve the original HEIF item graph:
  HDR gain maps, embedded thumbnails and metadata.
- When a linked HEIC original candidate expires or is evicted, the encoder
  retains bounded dimensions-only risk markers for the Photos process session.
  If the HEIC original can no longer be authenticated, it refuses a risky
  single-frame raster HEVC fallback instead of silently discarding assets.
- Existing numeric WIC trace now records rotation-match decline reasons.

Tradeoff:
The conservative guard can reject ordinary pixel edits to a different image
of the same dimensions, as source identity is not provable after lease expiry.
Use a fresh Photos process if necessary and protect the original. This guard
does NOT guarantee lossless metadata preservation for every possible workflow,
particularly if WIC never observed the original HEIC.

Safe installation:
1. Retain your current working WIC MSI and a method to restore it.
2. Close Photos and Explorer windows before installing.
3. Install WicHeic-HEIC-x64.msi (x64, ProductVersion 1.1.29).
4. Test only an intended COPY of IMG_4425.HEIC. Never overwrite the original.
5. Check thumbnail, 90 degree rotation, save, reopen, reverse rotation,
   and metadata/HDR/embedded-thumbnail preservation on the TEST COPY.
6. If a save error, loss of thumbnail or image corruption occurs, keep the
   original and affected copies/logs and restore your previous MSI.
7. Do not change codec registry priority or disable competitors as part of
   this installer trial.

Manifest:
- IMG4425_PILOT_SHA256.txt is generated by the same Windows CI run that
  built and validated the MSI, and contains its SHA-256 and source commit.
- Actual Windows 10 Photos UI validation remains to be done on a test copy.
