# HEICサムネイル自動先読み：試作ツール

## 目的と限界
Windows 10標準エクスプローラーでHEIC画像フォルダが前面に開かれた際、Windows Shellの\`IThumbnailCache\`経由で最大20枚（変更可）を低優先度・1スレッドで先読みする。元画像やHEIC Managerの設定は変更しない。

**これは独立した実験ツールであり、常時自動動作する機能ではない。** 試験中だけ実行し、標準で180秒後に自動終了する。スタートアップへの登録、常駐、レジストリ変更はない。閲覧していないフォルダを勝手に巡回しない。

## 将来の実機検証での手順（現時点は導入不可）
1. PowerShell 5.1で\`Explorer_HEIC_Warmup.ps1\`を開始。必要なら起動用cmdを追加する。
2. エクスプローラーで、人工HEIC画像の入ったフォルダを開く。フォト操作は不要。
3. プログラムは前面のエクスプローラーを最大180秒間監視し、未キャッシュHEICだけ生成する。再度同じフォルダに戻っても実行期間中は再処理しない。
4. タイムアウト時に自動終了し、件数のみを出力する。

\`-Mode Folder -Folder <dir>\`は開発者のCI検査用で、明示フォルダのみ1回処理する。\`-Mode SelfTest\`ではファイルの操作は行わない。

## 制限と安全条件
- 1スレッド、最大30枚、優先度BACKGROUND、40msの待機を設ける。
- 無許可のサブフォルダ探索、ネットワーク共有、ジャンクションを対象外にする。
- 完了ログは件数のみ。画像・パス・メタデータはログに書かない。
- Explorerが先に同一サムネイルを生成している可能性がある。実機で速度改善・CPU・HDD負荷の確認が必要。
- 既存のWIC 1.1.18は変更しない。
- 最終的にはJPEG同等の初回表示、10bit、EXIF/ICC/HDR保持、無再圧縮回転が合格条件。

## ダブルクリックで起動する場合（実機検証段階）
\`Watch_HEIC_Thumbnails.cmd\` と \`Explorer_HEIC_Warmup.ps1\` を同じフォルダに置く。CMDを1回ダブルクリックするとPowerShellの検証処理が起動し、**180秒後に自動終了**する。この間に通常どおりエクスプローラーを利用するだけで、前面に表示されたフォルダ内の未キャッシュHEICを最大20枚だけ先読みする。画像を個別に回転・編集・保存する操作は求めない。常駐も自動インストールも行わない。

**注意**：このCMDと前面Explorer検出の組み合わせは、Windows 10実機でまだ確認されていない。GitHub CIのWatchテストは「自動終了と例外がないこと」のみを検証し、実際にExplorerでフォルダを切り替えた検証ではない。配布・導入は未承認。

## 追加の安全措置
- 実際に閲覧しているExplorerウィンドウからフォーカスが外れた場合、そのフォルダの先読みを次の画像から中断する。既に実行中のShell API呼び出しは直ちには中断できない。
- フォルダ探索は最大500項目で打ち切り、対象20枚のために巨大フォルダ全体を走査しない。
- サブフォルダの親階層にジャンクション／シンボリックリンクがある場合も先読みを行わない。
- 同じフォルダへの再訪は180秒のセッション中は無条件に再実行しない。画像追加・ファイル更新の検知は未実装。
