# Windows 10標準フォト HEVC編集・回転の復旧に向けた調査ルート

## 五つの既存チャットの実機経過を再確認（2026-10-23）

- **2026-10-16**: Microsoft Storeの『HEVC Video Extensions from Device Manufacturer』（9n4wgh0z6vhq）を試したが**『このアプリはお使いのデバイスでは動作しません』**となり利用不能。120円の有料HEVC拡張は購入せず、完全無料という前提。メーカー提供版を再提案しない。
- **2026-10-19**: グローバルWIC v1.1.16を導入しExplorerサムネイルとWindows 10標準フォト表示に成功。HEVC有料拡張は未購入。
- **2026-10-20**: WicHeic Repair Test v1.1.18で標準フォトの回転保存に一時成功。ただし実装は再圧縮・EXIF消失を伴う。完成ではない。
- **2026-10-22 21:25 JST頃**: ユーザーが**v1.1.18をアンインストールしてからv0.4.0をインストール**したと明示。フォトでHEVC警告・編集回転不能が発生。v0.4.0は独立サムネイル専用で、グローバルWICの置換ではない。
- **2026-10-22 22:54 JST頃**: **v1.1.18再導入でHEVC警告が消え、標準フォトの編集・回転ボタンが復活したことをユーザーが直接報告。** これは『HEVC MFTがない限り編集ボタン復活は絶対不可能』という推論への重要な反例である。ただし再導入時のMedia Foundation MFT数は未測定であり、MFT=0だったと断定もしない。
- **2026-10-22 23:06 JST頃**: v0.4.0を除去した後も、v1.1.18単体で回転保存エラー、開いた画像とサムネイルの角度不一致、画面表示崩れを報告。**警告解除と保存の正常化は別問題。**
- **2026-10-22夜**: その後の異なるWIC試験版ではフォトの警告が消えず編集不能という実機報告もある。v1.1.18再導入の一時成功と矛盾させず、時点・配布DLL・登録・Photos状態の差として扱う。
- **2026-10-23 02:08 JST**: 実機診断はWIC v1.1.18の登録とHEVC MFT=0を確認。ただしその瞬間の標準フォト編集ボタン状態は測定していない。

**開発優先順位の訂正**: 必須HEVC拡張の導入を前提として進めるのではなく、過去に実機成功した**v1.1.18のグローバルWIC登録とフォト呼び出し条件**を起点に、現在のWIC候補と差分を追跡する。既に失敗したStore/メーカー向け無料版、CopyTrans HEICの再導入、有料HEVC拡張の購入を提案しない。さらに保存時の無再圧縮・全メタデータ保持は独立に検証する。

## 古い成功と現障害を区別する

2026-10-20のユーザー実機では、グローバルWIC v1.1.18を介してWindows標準フォトのHEIC回転保存に成功した。これはCI成功ではなく実機記録。ただし WriteSourceRaster -> EncoderCommitRecompressed による再圧縮、10bit→8bit、EXIF消失があったため、JPEG相当の無劣化保存とは言えない。

2026-10-23 02:08 JSTの既存実機診断はWindows 10 Pro build 19045、Microsoft Photos 2026.11090.22001.0、HEIF拡張1.2.48.0、HEVC decoder MFT 0件、グローバルWIC v1.1.18登録あり。同じWICを入れ直すだけで標準フォトのHEVC警告・編集無効が解消しなかった実機経過がある。

## 原因切り分けの優先順位

1. **旧v1.1.18登録下でHEVC警告が一時消失した実機事実から、フォトとグローバルWICの接続を調べる。** Microsoft公式のHEIF/HEVC説明は一般的な要件を示すもので、このPCでメーカー版を再入手できる証拠ではない。WIC登録あり/なし、バイナリ版、フォト状態を区別する。
2. **メーカー向け無料HEVC版は2026-10-16に実機で入手不能と確認済み。再提案しない。** 有料版購入も条件違反。HEVC AppX追加の提案ではなく、既存WICの履歴比較・再現経路解析に集中する。
3. 旧v1.1.18同等のグローバルWICを使用した状態で、**公開された人工HEICの作業コピーだけ**を用いフォトGUIの編集・回転有効化を確認する。旧版には保存破壊の既知問題があるため、ユーザーPCへの安易な再導入は求めない。
4. その後、Photos→WICの呼び出し方式と、無再圧縮保存時のEXIF/ICC/HDR/MakerNote/XMP/サムネイルを含む情報保全を検証・修正する。

## 追加した独立した読取専用情報

Photos_HEVC_AppXScope_ReadOnly.ps1 は **現在ユーザー / 他ユーザー / Windowsプロビジョニング** の3登録範囲だけを調べる。これは前回の read_only_diagnostic.json に含まれないスコープ情報であり、WIC / MFT / HEIC画像の過去の調査は繰り返さない。

取得失敗や閲覧権限不足は「不明」と扱う。Windowsの設定、ライセンス、写真、MSI、フォトアプリ、WIC、v0.4.0やHEIC Managerのどれも変更しない。結果は新しいJSONファイルとして保存し、ユーザーの実写真を一切読み込まない。AppX存在の確認はStoreでの購入権利・フォトからの実際の利用可否を証明しない。

必要になった場合だけ一回実行するための独立スクリプトであり、本体MSIに同梱しない。上記のWIC復活の実機証拠を踏まえ、現時点では追加のAppX診断を最優先しない。CIが合格してもWindows 10実機でのPhotos復旧を証明したことにはならない。

## 完成条件

Windows 10標準フォトGUIで表示・編集・回転・保存が可能なこと、人工HEICの原本が不変なこと、無再圧縮と画像・メタデータ保全、WICとv0.4.0の共存を満たして初めて完成版MSIを提示する。
