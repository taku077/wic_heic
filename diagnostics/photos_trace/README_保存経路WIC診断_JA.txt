HEIC保存エラー調査・WIC最終保存経路診断（Windows 10）
==================================================

【何を調べるか】
これまでの診断で、正常時にはHEIC保存→Shell通知→Explorer自動サムネイル更新が働くことを確認しました。
次に標準フォトで回転保存したとき、自作WICのエンコーダーCommit処理が
無再圧縮／再圧縮／拒否／失敗のどこを通ったか、HRESULTと所要時間を確認します。

【操作方法（手動コピーは不要）】
1. ZIPのファイルを全部同じフォルダーへ「すべて展開」します。
2. 「03_保存経路WIC診断_ダブルクリック.cmd」をダブルクリックします。
3. 診断したいHEICを選択します。
4. ツールが元画像と同じフォルダーに HEIC_SaveProbe_[一意ID].HEIC という作業コピーを自動作成します。
5. 監視画面が表示され、フォトでコピーを開きます。案内に従い90度回転して保存してください。
6. 回転保存に成功、または保存エラーを確認したら「結果を保存」ボタンを押します。
   ファイルの変更を検知した場合は、約10秒後に自動終了する場合もあります。
   最長90秒です。
7. 診断結果のフォルダーと集計結果のメモ帳が開きます。
   「診断結果」の HEIC_Save_WIC_Report_*.txt、HEIC_ShellWatch_*.txt と
   WIC_Photos_Trace_*.txt を報告してください。
   WICのトレースは開始ファイルと同じ場所に、その他の結果は「診断結果」に保存されます。

【安全上の注意】
・原本は読み取りだけ。保存するのは自動生成した作業コピーだけです。
・作業コピーは検証のため残します（自動削除しません）。
・MSIのインストール・自作WIC本体の更新は一切行いません。
・トレース取得中だけ HKCU\Software\WicHeic に TraceFile と
  TraceUntilFileTime を設定します。既存設定があれば開始を拒否します。
・正常終了とエラー終了時に解除を試みます。急な強制終了の場合も
  記録期限は最長約20分で切れます。ただし期限切れのレジストリ値は
  自動削除されないため、必要なら同梱 PhotosTrace_Stop.ps1 を実行してください。
・診断のテキストには写真名・写真パス・画素・Exif等を収録しません。
  PIDや時刻、HRESULT、形式、WICイベント名は収録します。
・インストール済みWICにトレース機能がない場合やフォトからアクセスできない場合、
  WICログが空になる可能性があります。空ログだけでWIC未使用とは断定しません。
・フォトで実際に画像が開いたかや、画像を保存できたかの最終確認は画面で行います。
  OSの「フォト起動要求成功」と実際の表示成功は別です。

【判定項目】
WIC_COMMIT_SUMMARY: 保存開始・成功・失敗・ログ不完全の件数
COMMIT: pid + operation 別の outcome、hr、route、所要時間
SHELL_FS_TARGET_EVENTS / SHELL_SHELL_TARGET_EVENTS: ファイル変更・Shell通知
ORIGINAL_SHA256_UNCHANGED=True: 原本が診断前後で全バイト一致

【解釈上の制限】
EncoderCommitExit=S_OKでも、フォトが最終ファイルを置き換えて成功した証明ではありません。
ファイル通知やHRESULTを時刻で突き合わせる必要があります。
診断ツールのWindows Server 2022での人工ファイル・人工イベントのCI成功は、
実機Windows 10フォトでWICログが記録される保証ではありません。
