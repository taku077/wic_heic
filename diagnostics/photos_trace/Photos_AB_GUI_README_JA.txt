Windows 10 標準フォト HEIC 実機 A/B 比較ツール v0.2（再実行対応）
========================================================

【まずはこれだけ】
1. ZIPを「すべて展開」してください（ZIP内のまま実行しない）。
2. 今インストールされている旧1.1.18はそのままにして、
   「01_Capture_OLD_118.cmd」をダブルクリックします。
3. 自動でエクスプローラーが開き、人工作業画像が選択されます。
   それを右クリック → 「プログラムから開く」→「フォト」で表示します。
4. 黒い画面に戻って Enter → 画面状態を 1 / 2 / 3 から選択。
   1 = 警告なし、編集と回転が使える
   2 = HEVC警告あり、編集と回転が使えない
   3 = それ以外・よくわからない
5. 回転保存を試したくなければ 0 と入力して完了です。
   保存確認は任意。元写真を使わないでください。

【やり直し】
・失敗しても「01_Capture_OLD_118.cmd」をもう一度実行するだけ。
・以前の「Existing synthetic session found」は修正済み。
・作業フォルダ、途中の結果、成功済み結果は自動削除・上書きしない。
・毎回、日時とランダム番号を付けた新しい作業フォルダを使う。
・以前のv0.1のフォルダが残っていても、このv0.2では止まらない。

【研究版との比較は後で】
旧1.1.18の確認は「01」だけで完了できます。
現在の旧1.1.18をアンインストールする必要はありません。

研究版を安全に導入できる段階になった場合のみ、別途
「02_Capture_RESEARCH.cmd」を実行し、最後に
「03_Compare_AB.cmd」で両者の違いを比較します。
「03」は両方の記録がある場合だけ使用してください。
複数回記録していても、最新のAと最新のBを自動選択します。

【結果ファイル】
Photos_AB_Results の中に
Photos_AB_A_日時_番号.json
Photos_AB_B_日時_番号.json
Photos_AB_Comparison_日時_番号.txt
を保存します。削除・上書きしません。
Aだけの調査の場合はAのJSONをチャットに添付してください。

【保護と限界】
・固定された人工HEIC（SHA-256確認済み）以外は使用しません。
・ソフトの導入、削除、レジストリ変更、実写真の処理はしません。
・表示は標準フォトを選択。HEIC Managerは選ばない。
・写真本体、実写真の撮影日時、EXIF内容は診断結果に含めません。
・旧版/研究版のPhotos内での実際のCOM呼出しを直接記録する
  ツールではありません。症状とWICの動作を比較するものです。
・本ツールは診断用です。警告や編集回転保存を修復するMSIではありません。
