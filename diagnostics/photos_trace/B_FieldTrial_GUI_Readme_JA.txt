Windows 10 標準「フォト」 HEIC 旧1.1.18 vs 研究版B 実機比較 v0.1
================================================================

これは「完成版」ではありません。原因比較のための期限なし手動試験用キットです。
本試験で改善する保証はありません。大切な画像は必ず試験から除外します。

【目的を限定】
旧1.1.18で確認済みの「警告なし・編集と回転ボタン有効」が、
研究版Bを入れるとどう変化するかを確認します。
画像の保存に伴う10bit→8bit降格、Exif消失も旧Aで検出済みです。
A側の実機診断は済んでいます。Aを再採取する必要はありません。

【含まれるもの】
・元の旧1.1.18 MSI（SHA256照合・復元専用）
・研究版B（1.1.20）のMSI（旧1.1.18とのGUI比較候補、未解決）
・WIC120_OneTimeTrial.ps1（インストール・復元の安全確認）
・B_Field_Install_Admin.cmd（Bを導入）
・B_Field_Restore_Admin.cmd（元の1.1.18に戻す）
・WIC_Preflight_ReadOnly.ps1 / WIC_Preflight_Compare.ps1
・SHA256の照合用TXT、固定人工作業HEIC

【最短の作業手順】
1. ZIPを「すべて展開」する。作業開始前に標準「フォト」の窓を全部閉じる。
2. 「B_Field_Install_Admin.cmd」を右クリック→「管理者として実行」。
   完了表示「WIC120_INSTALL_VERIFIED_WINDOWS10_PHOTOS_UI_UNTESTED」
   が出た場合だけ次へ進む。エラー時はそこで止め、ログを保全する。
   本キットは、現在の旧1.1.18 MSI/DLLの完全一致を確認しないと導入しません。
3. フォトを完全に終了した状態から開き直す。
   すでに作った別フォルダの「Photos_GUI_Real_AB_Compare_v0_2_Win10」にある
   「02_Capture_RESEARCH.cmd」を実行し、人工HEICでBを記録する。
   「03_Compare_AB.cmd」で既存のAと今回のBを比較。
   Aのやり直しは不要。結果は Photos_AB_Results 内の
   最新の Photos_AB_Comparison_*.txt です。
4. 比較が終わったら、フォトをすべて閉じる。
   このキットに戻り「B_Field_Restore_Admin.cmd」を右クリック
   →「管理者として実行」。旧版のMSI・COM/DLL復元を検証します。
   「WIC120_USER_BASELINE_118_FULL_RESTORE_PASS」が出て復元完了。
5. 比較レポート（txt）とB JSONのみ提出する。
   MSIログ、セッションJSON、事前点検JSONには環境パス情報が含まれる場合が
   あるため、求められていない限り共有しない。

【中止条件】
・旧1.1.18のMSI/DLLハッシュに不一致がある
・意図しないWIC登録または別のMSIがある
・Windowsビルドが19045以外
・MSI操作に失敗、再起動が必要、復元時に差異が出た
この場合は手動でレジストリを書き換えない、別版を追加導入しない。
ログを保存し、実写真は操作しないこと。

【制約】
・修正候補は現時点でHEVC警告・回転保存成功が実機未確認です。
・今回提供するものは実機A/B差分を得るための比較用です。
・ユーザーは明示的に管理者操作を選ぶ必要がある。自動導入しません。
・元の写真とHEIC Managerには触れません。バイナリ・Exif・ICCの完全保存
  を旧版と研究版で事前に保証するものではありません。
